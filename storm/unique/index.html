Module unique 

Source
Expand description

Unique indexes declared on the entity model and enforced inside transactions.

Declared with #[storm(unique)] on a field, or with #[storm(unique(fields = "a, b"))] on the entity for multiple columns. The derive generates a hash index (unique key -> entity keys) used to detect duplicates when a row is inserted or updated.

  • String values are compared using a Collation (case insensitive by default), and trimmed when one of the indexed fields is #[storm(trim)].
  • None is a value: only one row can have None for the same key.
  • A filter excludes rows from the index (like a SQL filtered index).
  • Use lookup on the generated index (or find) to search with a field value: the collation and the trimming are applied for you.
  • no_index generates no index: the duplicates are found with a table scan. Required for an entity key not based on u32 (ex: composite key).
