Module foreign_key 

Source
Expand description

Foreign keys declared on the entity model and enforced inside transactions.

Declared with #[storm(foreign_key(entity = Parent, on_delete = "..."))] on a field of an entity deriving Ctx. The derive generates a reverse index (parent key -> child keys) which is used to find the referencing rows when a parent is removed.

  • Inserting / updating a child fails when the referenced parent does not exist.
  • Removing a parent applies the OnDelete action to the referencing children.
  • OnDelete::Restrict is checked after the removing handlers, so they can detach the children first.
  • The children are found with a table scan, unless the reverse index is declared with index = "..." or already built.
  • The reverse index is a vec-based FlatSetIndex (requires u32 based keys), or a HashFlatSetIndex with hash, for parent keys not based on u32.
  • A key column can reference a parent with #[storm(foreign_key(column = "...", entity = Parent, key = 0))] on the type (key is the position in a composite key). The child is found by key for a single key, with a table scan for a composite key.
  • A parent defined in a crate depending on the child crate is declared with table = "..." instead of entity, and registered on the parent with #[storm(referenced_by = ...)] (see ExternalForeignKey).
