Expand description

Foreign key declared on the child with table = "..." instead of entity, for a parent defined in a crate depending on the child crate.

The child derive generates the marker (implementing this trait) and its reverse index. The parent registers it with #[storm(referenced_by = child_crate::{Child}{Field}Fk)], which enforces it as the ForeignKey External<Marker, Parent>.
